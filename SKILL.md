# Context-Skill: проект живёт в файлах, а не в контексте

Корень набора — папка, из которой прочитан этот файл (клон
`RungeKut/Context-Skill`); соседние скиллы — рядом. Агрегатор практик
ведения проектов; база `knowledge/` (карта —
`INDEX.md`, закон и агрегация — `00_ПРАВИЛА.md`). Общие правила — соседний
скилл skill-skill.

**Первым делом:** `git -C <корень> pull --rebase`; конфликт — разобрать до
работы.

Новый проект: `templates/AGENTS.md` → корень (как `AGENTS.md` и
`CLAUDE.md`), `templates/docs/` → `docs/`; сверка до нуля ошибок:

```bash
python <корень>/tools/check_project.py "<папка проекта>" > <корень>/local/report_<метка>.txt
```

Документы — 10-01…10-07, чек-лист ревью — 10-08, роли — 20-02.

## Железные правила

1. Вся работа — в файлы; точка возобновления — STATE.md ≤ 6 КБ (10-02).
2. Корневой файл ≤ 2 КБ (10-01); документ ≤ 6 КБ, ссылки вместо копий
   (10-03); INDEX «Файл | Когда» (10-04).
3. Сессия ~100–200К; шаг = коммит + STATE.md; compact рано и самим (20-04).
4. Агенту — бриф с путями, ответ ≤ 15 строк (20-01); завершённого не будить
   (20-03); архитектор — Plan, отчёт сверять (20-10).
5. Комментарии в коде запрещены по умолчанию (20-05).
6. В проекте push, деплой, прошивка, удаление — только с разрешения
   человека; исполнители не правят корневой файл и STATE.md.
7. GUI — только на скрытом столе, скилл hidden-desktop (20-11).
8. Квота Kimi (403/429) — не ретраить, скилл `quota-resume` (40-03).

## Правка набора

Запись по `00_ПРАВИЛА.md` (`source: практика P-nn`), строка в
`tools/when.txt`, `python tools/make_index.py`, строка в `CHANGELOG.md`,
`python tools/check_docs.py --project "<папка проекта>"`, `git diff`,
коммит, push сразу. В набор — ничего о рабочих проектах: только метки
`P-nn` (40-02).
