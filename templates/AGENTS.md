## Правила процесса (кратко; полный текст — в docs/00_rules/)

1. Контекст сессии держать ~100–200К; шаг = коммит + обновление STATE.md.
2. Документы — справочник, ≤ 6 КБ; устаревшее правим, не дописываем вниз.
3. Содержимое файлов не копировать — только ссылки на пути.
4. Комментарии в коде запрещены по умолчанию — должны доказать право на
   существование.
5. Задачи агентам — брифом из `docs/00_rules/agents.md`; ответ ≤ 15 строк.
6. Необратимые действия (push, деплой, прошивка) — только с разрешения
   человека.
7. Исполнители не правят этот файл и STATE.md — только верхний агент.
8. GUI-программы запускать и снимать только на скрытом рабочем столе (скилл
   `hidden-desktop`): не мешать человеку работать за машиной.
