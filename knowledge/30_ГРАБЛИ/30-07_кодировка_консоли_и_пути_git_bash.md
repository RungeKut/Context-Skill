# Кодировка консоли и пути Git Bash

## Что происходит

1. Скрипт печатает кириллицу в консоль — кракозябры или
   `UnicodeEncodeError`: кодировка вывода cp1251.
2. Нативный Python на путь `/e/папка/файл` отвечает `No such file`:
   такой путь понимает только Git Bash.

## Почему

Консоль и потоки вывода берут кодовую страницу Windows. Путь `/e/…` —
синтаксис оболочки, а не файловой системы.

## Как правильно

Задавать кодировку явно:

```bash
PYTHONIOENCODING=utf-8 python script.py
python -X utf8 script.py
```

Нативному Python давать путь `E:/папка/файл` или `E:\папка\файл`; в
скриптах использовать пути относительно файла (`os.path.dirname(__file__)`).

## Как неправильно

Лечить кракозябры сменой шрифта консоли. Передавать `/e/…` из Git Bash в
`python` и `subprocess`.

## Чем подтверждено

2026-10-19: вывод строки с кириллицей без переменной — не UTF-8, с
`-X utf8` — читается; открытие файла по `/e/…` — ошибка, по `E:/…` —
успешно.
