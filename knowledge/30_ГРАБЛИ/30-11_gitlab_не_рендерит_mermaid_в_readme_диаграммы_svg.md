# GitLab ломает mermaid в README — диаграммы готовыми SVG

## Что происходит

Блок ```mermaid в README валиден (весь текст парсится mermaid 8.13.6,
9.2.2 и 10.9.1 без ошибок), а страница файла на инстансе вместо диаграммы
показывает красное «Encountered an error while rendering: Parse error on
line 1: … Expecting 'NEWLINE', 'SPACE', 'GRAPH', got 'ALPHA'».

## Как диагностировать

По самому тексту ошибки рендера: «line 1» для многострочного графа —
переводы строк срезаны; `&quot;` внутри текста ошибки — кавычки HTML-
экранированы. Воспроизвести локально: в браузере прогнать через
`mermaid.parse` мутации своего текста (переводы строк в пробел или в
пустоту, `"` в `&quot;`) — мутация, дающая ту же ошибку, показывает,
что именно делает инстанс. Локальная проверка синтаксиса — рендер в
браузере с mermaid разных версий, а не глазом.

## Почему

Пайплайн инстанса передаёт содержимое блока рендереру через HTML-
экранирование и теряет переводы строк; причина в коде инстанса, файл в
репозитории корректен. Экранирование ломает любой синтаксис, где нужны
кавычки (подписи узлов), а срез строк — stateDiagram и sequenceDiagram,
где операторы разделены переводами строк.

## Как правильно

- Диаграммы — готовыми SVG в репозитории (рендер mermaid в браузере или
  CLI), в README — ссылки `![…](путь.svg)`; mermaid-исходники — рядом в
  `.mmd`, чтобы править и перерендеривать.
- SVG после рендера валидировать как XML: mermaid пишет в HTML-метках
  `<br>` без закрытия — `<img>` не показывает невалидный SVG; заменить
  на `<br/>`.
- В SVG добавить белый фон (`<rect fill="#ffffff">` после открывающего
  тега) — иначе невидим на тёмной теме.
- Рёбра к самому сабграфу (кластеру) рендер falls: соединять узлы
  внутри сабграфа, а не его идентификатор.

## Как неправильно

Править синтаксис (точки с запятой между операторами, отказ от кавычек)
и пушить вслепую за проверкой: экранная ошибка не меняется, потому что
искажение делается на стороне инстанса уже после markdown-парсера.

## Чем подтверждено

Практика P-01, 2026-11-02: три раунда правок синтаксиса не меняли
ошибку; переход на SVG-картинки устранил её полностью.
