# sed -i срезает CR у .bat

## Что происходит

`sed -i` в Git Bash на `.bat` убирает `CR` в конце строк. Глазами файл
прежний, но cmd разбирает его иначе.

## Почему

Предположительно текстовый режим Git Bash: `sed` пишет строки с `LF`.
Не проверено.

## Как правильно

Править `.bat` редактором или Python с `newline=""` (переводы строк
сохраняются как есть), затем `file x.bat` — должно быть CRLF. В
репозитории `.gitattributes` держит `*.bat text eol=crlf`.

## Как неправильно

Править `.bat` через `sed -i` и считать, что раз текст на месте, файл цел.
