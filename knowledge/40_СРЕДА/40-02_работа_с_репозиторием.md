# Работа с репозиторием

Набор — `https://github.com/RungeKut/Context-Skill`, ветка `main`.
**Порядок, обезличивание, стоп-лист, автор, соавторы, форк и разбор PR —
соседний скилл skill-skill, `knowledge/40_СРЕДА/40-02`** (там же
временное исключение на переезд). Коротко: в начале
`git -C <корень> pull --rebase`; после правки `git diff` глазами →
`python tools/check_docs.py --project "<папка проекта>"` → `git add
<файлы>` → `git commit` → **`git push` сразу**. Шаг = коммит.

Это правило самого набора. Правило для проектов, которые ведутся по
набору («push — только с разрешения человека», `templates/docs/00_rules/
git.md`), остаётся как есть.

## Обезличивание: проекты

Набор собирает практику из рабочих проектов, поэтому кроме общего списка:

* проект в записях, `CHANGELOG.md`, тексте коммита и PR — только меткой
  `P-nn`; ни названия, ни репозитория, ни пути, ни стека, по которому он
  узнаётся; имена людей — нигде;
* соответствие метки и пути — `local/projects.txt`, отчёты
  `check_project.py` — `local/report_<метка>.txt`; `local/` в `.gitignore`
  (00, раздел «Агрегация»);
* новый проект — строка в `tools/stoplist.txt` (свой, локальный) или в
  общий стоп-лист **до** первого коммита с его практикой.

Папку проекта для стоп-слов можно запомнить для клона:
`git config context.project "<папка проекта>"` — её учитывают
`check_docs.py` и хук.

## История

До 2026-10-28 push в набор делался по разрешению человека, хук и проверка
