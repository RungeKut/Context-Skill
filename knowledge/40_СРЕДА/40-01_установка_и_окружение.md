# Установка и окружение

Общий порядок (папка скиллов агента, хук, автор, стоп-лист, несколько
агентов, обновление) — соседний скилл skill-skill, `knowledge/40_СРЕДА/40-01`.
Для этого набора:

```bash
git clone https://github.com/RungeKut/Context-Skill.git "<папка скиллов>/context"
cd "<папка скиллов>/context"
git config core.hooksPath ../skill-skill/hooks
git config user.name  "<публичное имя>"
git config user.email "<публичный адрес>"
mkdir local                                   # реестр проектов и отчёты сверки
python tools/check_docs.py                    # до «Расхождений нет»
```

## Локальные файлы набора

Не клонируются, на каждой машине — заново (раньше их заводил установщик):

* `local/` — `projects.txt` (метка `P-nn` = путь к проекту) и отчёты
  `check_project.py`; в `.gitignore` (00, раздел «Агрегация»).
* `tools/stoplist.txt` — свой стоп-лист набора, по желанию: названия
  подключённых проектов; объединяется с общим стоп-листом skill-skill.
  Файл в UTF-8, строка — слово или фраза, `#` — комментарий.

## Зависимости

Только стандартная библиотека Python 3 (проверено на 3.13). Python — с
python.org, не заглушка Microsoft Store (skill-skill, 30-02).

## Проверка

`python tools/check_docs.py` и `python tests/test_tools.py` (сверка
проекта на временной папке; внешних программ не нужно).

## Переменные окружения агента (не проверено)

Из заметки о токенах; на нашей машине эффект не измерялся. Набор их не
читает — это настройки агента:

| Переменная | Назначение |
|---|---|
| `CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL` | время жизни кэша субагента, максимум 1 час; цена записи кэша выше (30-02) |
| `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` | отключает окно 1 млн токенов; автор заметки не советует включать без нужды |

## История

До 2026-10-28 установщик создавал junction из папок скиллов агентов в
`<корень>\skill`, задавал переменную с путём к клону и включал свой хук.
Отказались: переменная переживает перенос клона и ведёт в пустоту
(skill-skill, 30-01). Заметка той поры: пустой `Get-ChildItem -Recurse`
по junction в PowerShell 5.1 не означал поломку — проверять точечно
`Test-Path <путь>\SKILL.md`. Требования загрузчиков к `description` —
skill-skill, 30-06.
