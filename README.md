# Context-Kit

Правила ведения проекта с ИИ-агентами. Три связанные системы:

1. **Документация как внешняя память** — корневой `AGENTS.md`/`CLAUDE.md`
   ≤ 2 КБ с инвариантами, `docs/` с нумерованными разделами (00_rules…
   50_status), `INDEX.md` как таблица маршрутизации «Файл | Когда»,
   `STATE.md` как точка возобновления сессии.
2. **Работа с субагентами и архитектором** — роли по цене модели,
   бриф-шаблон «Цель / Читай / Пиши / Не делай / Ответ ≤ 15 строк», запреты
   (не будить завершённых, исполнителям не править корневые файлы, пути
   вместо содержимого).
3. **Экономия токенов** — цена вызова пропорциональна контексту (800К ≈ в 8
   раз дороже 100К), лимиты 100–200К, кэш 1 час / 5 минут, частый ранний
   compact по протоколу, запрет комментариев по умолчанию.

Дистилляция `docs/00_rules/` проекта `***_***` и заметки
«По поводу токенов».

## Состав

- `skill/SKILL.md` — сам скилл (читается агентом при срабатывании);
- `templates/AGENTS.md` — заготовка корневого файла проекта;
- `templates/docs/` — заготовка `docs/`: `INDEX.md`, `50_status/STATE.md`,
  `00_rules/` (agents, token-economy, compact).

## Установка скилла

Симлинки, как у остальных *-Kit:

```
<корень>/skill  →  ~/.kimi-code/skills/context
<корень>/skill  →  ~/.claude/skills/context
```

## Развёртывание правил в новом проекте

1. Скопировать `templates/AGENTS.md` в корень проекта (под имена
   `AGENTS.md` и, если нужен Claude, `CLAUDE.md` — содержимое одинаковое).
2. Скопировать `templates/docs/` в `docs/` проекта.
3. Заполнить инварианты, карту документации, команды сборки, разделы
   `10_…/20_…` под проект.
